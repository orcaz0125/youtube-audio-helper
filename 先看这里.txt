YouTube 音频助手 0.4.0
work by orcaz

Windows 10/11 x64 预览版：
1. 先安装 x64 Python 3.12+（勾选 Add python.exe to PATH）和 Node.js 22+。
2. 完整解压，Chrome 开启开发者模式，加载 extension 文件夹。
3. 双击 install-windows.cmd，等待安装完成。
4. 重新加载扩展，刷新 YouTube 页面。
5. 可运行 check-windows.cmd 检查本机通信及测调。

macOS：
加载 extension 后运行「安装本机程序.command」。
需要 Python 3.12+、Node.js 22+、Homebrew 和 Xcode 命令行工具。

只保存 MP3；调性与 BPM 自动写入文件名，无需确认。
Windows 已完成编译及跨平台配置测试，尚未进行 Windows 实机验证。
