YouTube 音频助手 · 分享版 0.3.0（macOS）
======================================

功能
----
打开 YouTube 视频后点击「下载音频」，自动保存 MP3。
使用 libkeyfinder 2.2.8 分析整首音频调性，调性和 BPM 直接写进文件名。
例如：歌名 [F# Minor] [128 BPM].mp3
只保存 MP3，没有额外的 JSON 分析文件，也无需确认调性。

首次安装（只做一次）
------------------
1. 把整个文件夹放到固定位置，不要放进临时目录。
2. 在 Chrome 地址栏输入 chrome://extensions，打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本文件夹里的 extension 文件夹。
4. 双击「安装本机程序.command」，等待安装完成。
   本分享版自动配置扩展 ID，不需要复制、粘贴 ID。
5. 刷新 YouTube 视频页面，点击右下角「下载音频」。

如果 macOS 无法直接打开 command 文件：
打开「终端」，输入 zsh 和一个空格，把 command 文件拖入终端，按回车。

需要的环境
----------
• macOS 和 Google Chrome。目前在 Apple Silicon Mac 上验证过。
• Python 3.12 或更新版本：https://www.python.org/downloads/macos/
• Homebrew：https://brew.sh/
• Xcode Command Line Tools：可在终端运行 xcode-select --install 安装。
• Node.js 22 或更新版本：https://nodejs.org/ （YouTube 解析需要）
• 能访问 YouTube 和依赖下载源的网络。

安装程序会安装 Python 依赖，通过 Homebrew 安装 libkeyfinder，并在你自己的
电脑上编译测调程序。这是首次联网安装包，不是免依赖或离线安装包。
此包不支持 Windows。

下载的文件在哪里
----------------
访达 → 音乐 → YouTube Audio
路径：~/Music/YouTube Audio
下载完成后也可以点击「在访达中显示」。
本机程序安装在 ~/Library/Application Support/YouTube Audio/host。
请保留 extension 文件夹的位置，移动后需要重新加载扩展。

调性和 BPM 的来源
-----------------
调性优先使用 libkeyfinder 对整首源音频的分析结果。
标题、介绍里的调性标注仅作为参考，音频无法测出时才回退使用。
BPM 优先取明确的视频标注，缺失时使用 librosa 节拍跟踪估计。
结果中会标明来源。自动测调可能误判，必要时可以自己改文件名。

连接问题
--------
打开扩展弹窗，点击「检查连接」。
如果不成功，重新运行「安装本机程序.command」，然后在 chrome://extensions
点击扩展的 ↻ 重新加载，再刷新 YouTube 页面。
日志：~/Library/Application Support/YouTube Audio/host/native.log

Chrome 内的代理不一定覆盖本机程序。受登录、年龄或机器人验证限制的视频
可能无法下载。请仅保存你有权下载的内容。

卸载
----
双击「卸载本机连接.command」，再在 Chrome 管理页移除扩展。
已下载的音频会保留，本机程序目录可以按需自行移除。
